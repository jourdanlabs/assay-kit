FREEZE canonicalization `v1` hashes one byte stream: the ASCII domain separator `assay-freeze-v1` followed by NUL, then, in the fixed order `PROTOCOL.md`, `CORPUS.sha256`, `PINS.txt`, each UTF-8 filename followed by NUL, its byte length as one unsigned eight-byte big-endian integer, and its unmodified file bytes; `FREEZE.sha256` records that digest, so line endings, final newlines, and every other byte remain significant. Compatibility mode `v0` reconstructs ASSAY-001's historical two-line sha256 manifest from the unmodified bytes of `PROTOCOL.md` and root `AMENDMENT-1.md`, using the published legacy artifact names and the amendment date in its heading, and `freeze --verify --canon v0` succeeds only when those reconstructed bytes exactly equal the existing `FREEZE.sha256`.
